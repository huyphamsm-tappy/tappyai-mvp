Why commit-msg and not pre-merge-commit: git skips pre-merge-commit when a merge stops on conflicts
and is finished with `git commit` — the exact path of a6ca9f0 / 1e7b77e. commit-msg runs for both
`git merge` and `git commit`, and sees the final message (so a Merge-Drop trailer is honoured).
