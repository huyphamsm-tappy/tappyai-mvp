## 6. Cache verification — and a pre-existing defect found

**Unit level:** `shared` is byte-identical across five configurations (language, memory, prefs,
GPS, planning, image, and all three decision stages). Mutation S8 proves that test bites.

**Live probe, 5 variants differing only in `dynamic`:**

| variant | cacheRead | cacheCreation | verdict |
|---|---|---|---|
| A vi cold comparison | 13,101 | 13,101 | cold — expected, the prompt just changed |
| B en cold comparison | 26,202 | **0** | 100% hit |
| C vi refinement (prior turn) | 26,202 | **0** | 100% hit |
| D vi + GPS | 26,202 | **0** | 100% hit |
| E vi + budget + prefs | 13,226 | **13,226** | ⚠️ forked |

**E was investigated before continuing, as STEP 6 requires.** `shared` did not change. The fork
comes from **outside `shared` but inside Anthropic's cached prefix**: tool definitions sit ahead
of the system blocks, and `route.ts` interpolates the user's budget into the
`get_hotel_prices` **description** (`. BUDGET FILTER: … duoi ${budget.max} …`).

Isolating test — same request, budget varied, nothing else:

| request | cacheCreation |
|---|---|
| `Khách sạn Đà Nẵng` | 0 — reused the 13,101 lineage |
| `Khách sạn Đà Nẵng dưới 2 triệu` | **13,226 created** |
| `Khách sạn Đà Nẵng` | 0 — back on 13,101 |
| `Khách sạn Đà Nẵng dưới 3 triệu` | **13,226 created again** |

> ### 🔎 Pre-existing defect (NOT introduced here, NOT fixed here)
> **Every distinct budget value forks a fresh ~13.2k-token cache creation at 1.25×.** A third
> lineage (12,953) exists for `locationIntent === 'offline'` turns, where `search_products` is
> dropped from the tool set — the tool block again. `shared` being byte-stable is **necessary
> but not sufficient**; the cached prefix includes the tools. This predates C3-B and belongs to
> Cost Optimization, which this phase must not modify. **Flagged for owner routing.**

Incidentally, the C3-B.2 `locationIntent` fix **reduces** fragmentation: `Mua tai nghe bluetooth
ở đâu` used to land on the 12,953 lineage and now reads the majority 13,101 one (26,202 / 0).

**Acceptance:** 100% cache hit and 0 creation on every warm variant of a given tool signature.
The creations observed are one per prefix signature, all traced to pre-existing tool-block
variation. **No user, language, comparison or stage data entered `shared`.**
