# TappyAI browser extension

Manifest V3, Chrome / Chromium / Edge. Permissions: `activeTab`, `contextMenus`, `storage` — nothing else.
Right-click a selection, a link or a page → ask Tappy / check with Scam Shield. No tracking, no history, no network.

Full documentation, permission rationale, privacy rules and the install steps: `docs/growth/BROWSER_EXTENSION.md`.
The URL contract is pinned by `src/lib/growth/browserExtension.test.ts` in the web repo.
